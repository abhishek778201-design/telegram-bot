# 🎯 Telegram Quiz Platform

A production-grade multi-bot Telegram quiz platform with Creator Bot, Runner Bot, and Mini App.

## Features
- Quiz creation (text, polls, files, AI)
- Multiple modes (standard, sectional, practice, exam)
- Smart filtering & editing
- Payments & analytics
- HTML/PDF reports

## Setup
1. Copy `.env.example` to `.env`
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python run.py`

## Deployment
- Docker deployment available
- Railway/Heroku compatible
- GitHub Actions CI/CD
